What it is

Overview

A research project for an MFin ML elective — and a deliberately careful one. The brief was "build a stock-picking model"; the temptation in that brief is to fit something flashy on a randomly-shuffled holdout and report the in-sample Sharpe. This project does the opposite.

The pipeline ingests price history for a basket of US equities, engineers technical and statistical features (returns, moving averages, volatility, momentum, PCA on the cross-section), and trains an LSTM to forecast a forward return signal. The signal is then calibrated, ranked cross-sectionally, and fed into a long-only portfolio with explicit position sizing and turnover penalties.

Validation is strictly walk-forward — the model is refit on rolling windows so no future bar is ever visible to a past prediction. Costs and slippage are charged at the trade level, not bolted on at the end as a fudge factor. The whole thing is reported with confidence intervals, not point estimates.

The result is a strategy that does not look as impressive as a leaky backtest would — and that is the point. The full notebook walks through every choice and shows the equity curves, drawdowns, and feature importances side by side.

What's inside

Pipeline
№ 01

Feature engineering

Technical indicators, rolling statistics, and PCA on the cross-section to compress correlated features into orthogonal factors.

№ 02

LSTM forecast

A sequential model that consumes feature windows and emits a forward-return forecast, trained with early stopping and dropout.

№ 03

Calibration

Raw model outputs are calibrated so the resulting signal has a meaningful probability interpretation — not a black-box scalar.

№ 04

Walk-forward backtest

Rolling refits with no peeking. Each bar is predicted only by a model that has never seen it. Refit cadence is a config knob.

№ 05

Cost & turnover

Trade-level slippage and commission, plus an explicit turnover penalty that biases the optimiser away from churn.

№ 06

Reported honestly

Equity curves, drawdowns, hit rates, and feature importance — with confidence bands, not single point estimates.

How it's built

Stack
LanguagePython 3 — single Jupyter notebook, designed to run top-to-bottom on a fresh kernel.
DataYahoo Finance price history for the universe, plus engineered technical features.
ModelLSTM (PyTorch / Keras) for the sequential forecast. PCA from scikit-learn for cross-sectional decorrelation.
ValidationWalk-forward backtest with rolling refits — no shuffled splits, no information leakage.
Reportingmatplotlib + pandas — equity curves, drawdowns, rolling Sharpe, feature importances.
DeliverablesThe full notebook (also rendered as HTML), a written report, and a README.
