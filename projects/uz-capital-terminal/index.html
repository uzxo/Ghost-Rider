What it is

Overview

Most retail brokerages give you a list of holdings and a P&L number. UZ Capital is what happens when you ask: what would it look like if I built the same view a hedge fund would use, just for myself?

The terminal aggregates positions across three brokerage rails — equities, crypto, and ETFs — into a single source of truth. It pulls live prices from public APIs, computes cost-basis-aware P&L, and breaks risk down by sector, factor, and concentration. There's a transactions ledger, a dividend tracker, a closed-trade book, and a quant equity screener that scores tickers on a rules-based factor model.

The aesthetic is borrowed from institutional terminals — dense data, monospace numerics, semantic color, dark-first surfaces — because the goal was to feel like a tool, not a marketing page.

This public version uses entirely fabricated holdings, transactions, and P&L. The structure is real; the numbers are mock. Read on for what's under the hood.

What it does

Features
№ 01

Cross-platform aggregation

Equities, crypto, and ETFs unified into a single book with weights, P&L, and per-platform allocation chips.

№ 02

Live pricing

Yahoo Finance for equities & ETFs, CoinGecko for crypto, with automatic CORS proxy fallback and exponential retry.

№ 03

Risk & exposure

Sector breakdown, concentration risk, portfolio beta, and a drawdown chart that surfaces the worst peak-to-trough.

№ 04

Quant equity screener

A rules-based factor model that scores a watchlist on growth, valuation, profitability, and momentum signals.

№ 05

Transactions & dividends

Full ledger of buys, sells, and dividend payments with sortable columns and a CSV export.

№ 06

Closed-trade book

Realised P&L tracked per round-trip, with hit rate and average win/loss, mirroring how a fund books trades.

How it's built

Stack
FrontendVanilla HTML, CSS, JavaScript. No build step, no framework. One file, ~3.9K lines, ships as a static asset.
ChartsChart.js 4 — line, donut, bar, and stacked area for allocation and drawdown views.
DataYahoo Finance v8 spark API for equities & ETFs, CoinGecko simple-price API for crypto. Resilient via a CORS-proxy waterfall.
StateIn-memory portfolio model with computed selectors for cost basis, market value, sector exposure, and weighted beta.
DesignDM Sans + JetBrains Mono. Dark-first surfaces, semantic color tokens (green/red/blue/gold), and a 12-column dashboard grid.
HostingGitHub Pages — same as everything else in this portfolio.

Run locally

Live prices

The hosted version pulls prices through a chain of free CORS proxies. They work, but they get rate-limited under public traffic.

Running the terminal off your own machine bypasses the shared rate limits — Yahoo Finance and CoinGecko respond directly to your IP, and the hero total ticks live within a couple of seconds.

The repo ships with a one-command launcher: start.sh. It boots a static HTTP server on port 8090 and opens the terminal in your default browser.

Requires Python 3 (preinstalled on macOS and most Linux distros). Nothing else.

# 1. Clone the repo (or download the project folder)
git clone https://github.com/uzxo/Ghost-Rider.git
cd Ghost-Rider/projects/uz-capital-terminal

# 2. Launch — opens http://localhost:8090/terminal.html in your browser
bash start.sh

# 3. Stop with Ctrl+C when done.
